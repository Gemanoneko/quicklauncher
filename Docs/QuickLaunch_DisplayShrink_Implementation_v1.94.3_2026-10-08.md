## Behavior and root cause

The previous display path could clamp a radial window smaller than its exact chip/hub geometry; the renderer's layout-switch path also cancelled active name drafts. Preferred Fan/Ring and current presentation are now separate. Main computes the actual stored-count rounded geometry, including empty n1 and direction, with the existing 24px reserve per side. An impossible radial presentation uses runtime Grid; a legal preferred layout restores from its home/anchor. Existing legal legacy placement is retained. When no legal functional minimum fits, the runtime host stays suppressed and the Manager reports the approved display-too-small status. Suppression does not change saved hidden preference. Work areas smaller than Manager's existing 440x420 functional minimum are explicitly logged as unsupported, with no automatic Manager opening.

Runtime adaptation never writes layout, Fan direction, home, radial anchor, radial dimensions, gridSize, item order, files or settings. Deliberate temporary-Grid movement translates preferred rect and canonical radialAnchor by the actual movement delta, incorporating any pending accepted placement; only rect/anchor/home are saved. Temporary resize changes the current viewport only. Explicit Grid conversion adopts its visible bounds through the existing save route; other validated layout/direction choices retain their existing rules. A validated Fan direction that makes a suppressed region fit reveals the safe host while preserving global hide and shape-failure state.

The same live input node and draft listeners survive automatic radial-to-Grid conversion and later tile rebuilds. Filter and edit state survive. Restoration waits while rename or geometric interaction remains active; display invalidation cancels geometric targeting first, restores an interrupted region movement to its accepted baseline, and prevents a late internal/file-drop callback from committing. The controller continues to enforce preferred radial capacity, actual prospective fit and global icon-size preflight even while drawing Grid.

Grid's functional minimum is measured from actual theme bands, intrinsic control widths, actual scroller padding and visible tile/rename height. Until a matching measurement is available, the host remains hidden; stale theme/icon measurements cannot reveal it. The existing Grid renderer, art scroller, resize rim and controls are reused. Temporary-only CSS enforces the already approved 24px floor on Clear filter, edit buttons and rename inputs. The resize title is the approved `Resize temporary Grid`. Manager rows retain the preferred layout selection and show `Fan · using Grid`, `Ring · using Grid` or the approved suppression copy. Ordinary notices use the existing eight-second slot and wait behind active refusal/notice or actionable update state. No new button, panel, menu route or IPC privilege was added.
