## 0.1 Common frame and motion contract

Inherit audit C1/C3–C5 and H1–H8, Foundation A/B and Batch06 §0.1–0.2. The font README's eleven approved files supersede the Foundation's historical seven-file inventory. Use no other downloaded or locally installed non-stock family.

- **Zero infinite animations in all seven.** Remove legacy whole-window flash/shadow, ghost readout, moving particles, scrolling backgrounds, title flicker, icon pulse and animated hover sheen. Keep established functional transition behavior only; no ambient motion or added blur. Preserve existing base backdrop blur: this spec does not authorize its removal.
- Remove old panno drawings and flavour text that occupy the tile field, including edit-bar pseudo quotes. No glyph, schematic, ring, figure or hard-edged silhouette behind any tile or label. Keep only bounded static texture/soft tone in that area. `#app::after` has no content-obscuring art. All noninteractive art uses `pointer-events:none`.
- Grid art belongs in the existing scrolling frame background, not a fixed overlay above tiles; preserve Grid scroll containment and its gutter. Use the previous batch's **8px outer bands** and four-pixel tile/focus keep-out. No art may enter the dynamic tile field in Grid, Fan or Ring. If a radial shape leaves no safe band, omit that frame layer in that layout; do not draw through radial icons to preserve a motif.
- Header motif uses the inherited explicit **84×20px** art box (`right:172px; top:10px`) where that box exists; hide at widths below 424px and whenever filter-chip/rename/control geometry leaves insufficient room. Art starts at x168 in the legacy 424px header, title edge ≤156px. For dynamic region titles the **actual title and control rects** govern: suppress art before they collide, preserve full title behavior, never reposition the controls or shrink their targets for art.
- Header lines paint inside the 40px strip. Banner art stays in its existing seven-pixel top seam, 22×22px left icon slot and optional bounded right motif. Preserve the one-line banner-fit mechanism and all existing rotation strings. No new quote lookup or invented lore text is needed. Use current arrays as authored, with one-line fit/capture of each reachable string; do not silently rewrite copy to make a font fit.
- Decorative motif cuts belong to plates/frame only. **Never clip the app glyph.** Retain known thematic plate silhouette if a real-icon test passes; inset/scale the plate rather than the icon. A plate cut must not exceed the approved 20px ceiling. If an existing polygon crops a glyph, unclip its icon wrapper and keep the silhouette on the plate.
- No text halos, icon glows or full-window vignette over content. `--glow-*`, `--pulse-glow`, `--scanlines` and theme tile shadows are none. Default icon filter is identity (`none`); do not dim dark-theme app icons below their original luminance.

These constraints follow recognition over recall and minimalist design (NN/g), adequate target access (Fitts/WCAG), and familiar Windows utility behavior (Jakob/Fluent); franchise identity comes from frame/type/material, not altered interaction.

Token mapping is part of the spec, not optional palette advice:

- `--bg`, `--panel-bg`, `--overlay-bg` (panel), `--header-bg`, banner background use their table surfaces. Title, tile labels, banner text, form labels, tooltip text and ordinary control text use **text**; functional secondary/version/empty-state copy uses **dim**. `--text-dim` and `--hint-sub-color` are dim. - `--accent-c`, `--accent-text`, `--accent-m` and `--accent-y` use functional accent unless an explicitly scoped decorative stripe below calls for a different ink. This avoids accidentally painting a title dot, hotkey recording state, selected control or update copy in a decorative low-contrast colour. `--edit-label-color`, `--btn-done-color`, `--btn-close-color`, `--update-color` are text or accent, **never the dark decorative blood colour**.
- Buttons, tile hover, picker hover and rename input hover use hover fill; button pressed, tile pressed, active picker/skin, selected Manager row and recorded hotkey use pressed fill. Their foreground remains text/accent. Rest form fields use panel. Apply relevant tokens including `--btn-hover-bg`, `--btn-active-bg`, `--tile-hover-bg`, `--tile-active-bg`, `--picker-search-bg`, `--picker-item-hover-bg`, `--picker-item-active-bg`, `--picker-placeholder-bg`, `--skin-btn-active-bg`, `--rename-input-bg` and edit/update fills consistently.
- Borders, rename dashed outline, dropdown/form outline, actionable empty-state icon and drop hint use border or functional accent. Hover border uses focus. Focus is a solid visible ring with existing size/offset and must contrast ≥3:1 against every adjacent painted surface. Do not change geometry of F5 or Manager controls.
- Remove/error controls: dark themes use `#70222C` opaque fill with `#FFF4F0` glyph at rest and hover/pressed; Silent Hill uses `#79261C` fill and `#FFF4F0` glyph. Override the reachable remove-button foreground/state rule if necessary **inside the same theme**, so the inherited OKLCH hover does not bypass the intended fill/contrast. Functional error text uses `#F1B5B7` on dark surfaces and `#79261C` on Silent Hill. Preserve the actual error message and status meaning.
- Light Silent Hill requires explicit dark foregrounds for the filter-clear hover, selected rows, hotkey states, menus and tooltips; inherited literal white is not safe. Scope overrides to this theme and the actual selector. Use text/accent, never whiten a hover label over its pale surface.

Ratios are requirements: all ordinary functional text ≥4.5:1, non-text controls/borders/focus/action icons ≥3:1, actual app icons ≥3:1 where the previous batch icon diagnostic measures them. The proposed opaque table colours were arithmetically screened over all five table surfaces; this **does not measure art, alpha compositing, inherited CSS or actual icons**. Ender reports real lowest pairs and rendered overrides. If a pair fails, adjust the offending foreground toward text, remove texture under it or reduce fill strength within this direction; send Judy the exact changed value and ratio for review. Never lower a threshold or rebaseline a redesigned theme.
